# Pratibha Mittal - Portfolio

Static site, no build step.

- `index.html` - the whole site (HTML, CSS, JS)
- `images/hero.jpg` - your photo
- `images/cutout.webp` - background-removed cutout of you, used on the intro title screen
- `images/avatar.jpg` - face avatar (on plum background) for the "Who's watching?" profile card

Run: open `index.html` in a browser (needs internet once for Google Fonts).
Deploy: drag this folder to Netlify Drop, or push to a GitHub repo and enable GitHub Pages.

Edit: text lives in `index.html`; skills and journey data are the `S` and `J` arrays near the bottom.
